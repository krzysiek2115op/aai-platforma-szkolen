# TRZY REGUŁY WYPROWADZONE POMIAREM (2026-08-23), nie zmieniać na oko:
#  * PANEL Z POLEM WYSZUKIWANIA (`/config`, `/status`, `/permissions`,
#    `/plugin`) NIE zamyka się jednym Esc — pierwszy czyści wyszukiwanie
#    („Esc to clear" w stopce panelu). Jeden Esc zostawia panel otwarty,
#    kolejne `WPISZ` ląduje w polu wyszukiwania, a `ENTER` PRZEŁĄCZA
#    podświetlone ustawienie — tak zniknął właścicielowi `autoCompactEnabled`
#    (2026-08-23). Dlatego po każdym panelu stoją TRZY Esc. Trzy osobne
#    `KLAWISZ esc` dzieli 0,6 s, więc nie składają się w double-tap i nie
#    otwierają menu cofania;
#  * TEKST zostawiony w polu NIE znika od pojedynczego Esc. Bez posprzątania
#    kolejne komendy DOKLEJAJĄ się do poprzednich (`/co` + `/sum` + `@` =
#    `/co/sum@`), a taka skleina zostaje WYSŁANA DO MODELU zamiast otworzyć
#    panel. Sprzątamy więc `KLAWISZ esc` (zamyka menu podpowiedzi) + `KASUJ <n>`.
#  * WYCZYSC przy PUSTYM polu OTWIERA MENU COFANIA i połyka wszystko, co
#    wpiszemy dalej — dlatego po sobie sprzątamy `KASUJ <n>` (tyle
#    backspace'ów, ile znaków wpisaliśmy), a WYCZYSC wołamy raz, świadomie,
#    właśnie po to menu cofania.
